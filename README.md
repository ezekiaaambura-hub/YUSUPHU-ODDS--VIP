# YUSUPHU ODDS VIP

Prototype ya app ya kuuza VIP Odds.

## Kuanza locally

```bash
npm install
npm start
```

Kisha fungua:
http://localhost:10000

## Render

Build Command:
```text
npm install
```

Start Command:
```text
node server.js
```

Port inasomwa kupitia `process.env.PORT`.

## Muhimu

Hii ni prototype. Payment ya TSh 5,000 na database ya production bado hazijaunganishwa. Kabla ya kutumia malipo halisi, ongeza payment gateway, uthibitishaji wa malipo, authentication ya admin, database ya production, HTTPS na security controls.
